# ASHLINE 0.3 playable PC builds

This branch contains verified prebuilt native archives. Source code is on `main` and tag `v0.3.0-alpha`.

Sign in to GitHub with repository access. Click an archive, then click **Download raw file** (download icon) on its file page.

- [Windows x64](ASHLINE-0.3-Windows-x64.zip): extract fully, launch `ASHLINE.exe`.
- [Linux x64](ASHLINE-0.3-Linux-x64.zip): extract fully, make `ASHLINE.x86_64` executable, launch it.
- [Source archive](ASHLINE-0.3-Source.zip)
- [Actual screenshots](ASHLINE-0.3-Screenshots.zip)

SHA-256 checksums are in `ASHLINE-0.3-SHA256.json`. Platform archives include controls, OpenGL fallback launchers, licenses and handoff instructions.

Early alpha. Windows was exported but not runtime tested. Linux Vulkan/OpenGL runs were inspected; hardware GPU performance is not validated.
